# THE MONOCLE — Meta Layer

## Purpose
The Monocle defines **how systems are seen**, not **what they do**.

- **Nature:** Non-executive, non-runtime, interpretive.
- **Scope:** Lenses, invariants, translation rules.
- **Output:** Constraints and clarity, not behavior.

## Boundary
- No execution.
- No onboarding.
- No public narrative.

## Relationship
- Domain scaffolding lives elsewhere.
- Public interfaces live elsewhere.
- The Monocle governs **perspective**, not implementation.

## Invariants
- Lenses are explicit and inspectable.
- Models remain separable from reality.
- Resonance without identity fusion.
- Canon before interface.

## Directory Map
- lenses/        — defined viewpoints (read-only)
- invariants/    — non-negotiable constraints
- translations/ — rules mapping between layers
- notes/        — operator-only annotations
